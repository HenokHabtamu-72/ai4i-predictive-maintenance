# Predicting Machine Failure in a Milling Process (AI4I 2020)

EGN 2203 – Introduction to Data Science, course project.

The notebook applies the full data-science workflow to the **AI4I 2020 Predictive Maintenance
Dataset**: 10,000 simulated machining processes with air and process temperature, spindle speed,
torque, tool wear and a machine-failure label. It covers data cleaning, exploratory analysis,
three hypothesis tests (t-test, chi-square, ANOVA), physics-based feature engineering
(mechanical power, tool wear × torque, temperature difference) and three classifiers (logistic
regression, decision tree, random forest).

**Headline result:** a tuned random forest catches 58 of the 66 failures in the held-out test set
with 3 false alarms (F1 = 0.91, ROC-AUC = 0.99). Most of the failures it misses are tool-wear
failures, whose timing the simulator randomises.

## Data

Download the dataset from the UCI Machine Learning Repository
(<https://archive.ics.uci.edu/dataset/601>, DOI [10.24432/C5HS5C](https://doi.org/10.24432/C5HS5C),
licence CC BY 4.0) and save `ai4i2020.csv` in a folder called `data/` next to the notebook.
The notebook also finds the file if it sits directly next to the notebook.

`data/` is listed in `.gitignore`, so the CSV files are **not** in the repository. Anyone who
clones the repository has to download the data first.

## Running

* **VS Code or Jupyter:** open the notebook, select the `.venv` interpreter as the kernel, and
  choose *Run All*.
* **Command line** (runs every cell and saves the outputs into the notebook):

  ```powershell
  .venv\Scripts\python.exe -m nbconvert --to notebook --execute --inplace EGN2203_Project_GroupX.ipynb
  ```

A full run takes about 1–2 minutes. Every random step uses `RANDOM_STATE = 42`, so repeated runs
give identical numbers.

## Important caveat

AI4I 2020 is a **synthetic** dataset: it was generated by a simulation with documented failure
rules, not recorded on a real machine. Section 7 of the notebook discusses what this means for
applying the results to a real machine tool.
